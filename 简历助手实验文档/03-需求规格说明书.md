# 需求规格说明书

## 一、引言

### 1.1 项目名称
智能简历助手微信小程序

### 1.2 文档目的
本文档详细描述智能简历助手的软件需求规格，作为项目设计、开发和测试的依据。

### 1.3 读者对象
- 项目开发人员
- 测试人员
- 项目管理人员

## 二、功能需求

### 2.1 用户认证模块

| 需求编号 | 需求名称 | 需求描述 | 优先级 |
|---------|---------|---------|--------|
| AUTH-01 | 用户注册 | 用户通过用户名、密码、邮箱、昵称注册账号 | 高 |
| AUTH-02 | 用户登录 | 用户通过用户名和密码登录系统 | 高 |
| AUTH-03 | 用户名检查 | 注册时实时检查用户名是否已存在 | 中 |
| AUTH-04 | 个人信息管理 | 用户可查看和编辑个人资料（昵称、手机号、头像等） | 中 |

**输入/输出规范**：
- 注册接口：POST /api/auth/register
- 登录接口：POST /api/auth/login
- 用户名检查：GET /api/auth/check-username?username=xxx

### 2.2 简历生成模块

| 需求编号 | 需求名称 | 需求描述 | 优先级 |
|---------|---------|---------|--------|
| RESUME-01 | AI简历生成 | 用户输入姓名、所学专业、工作年限、个人技能，AI生成专业简历 | 高 |
| RESUME-02 | 所学专业输入 | 用户自由输入专业名称（如计算机科学），替换简历类型选择 | 高 |
| RESUME-03 | 生成结果预览 | 展示AI生成的简历内容 | 高 |
| RESUME-04 | 生成历史保存 | 自动将生成的简历保存到历史记录 | 高 |

**输入规范**：
- 姓名（必填，2-20字符，禁止特殊字符）
- 所学专业（可选，最多30字符）
- 工作年限（可选，0-60年，纯数字输入）
- 个人技能描述（可选，最多500字符，至少2字符）

### 2.3 简历评估模块

| 需求编号 | 需求名称 | 需求描述 | 优先级 |
|---------|---------|---------|--------|
| EVAL-01 | 简历上传 | 支持上传.txt格式简历文件 | 高 |

| EVAL-03 | 评估维度选择 | 用户可选择需要评估的维度 | 中 |
| EVAL-04 | 评估结果展示 | 展示AI评估结果和优化建议 | 高 |

### 2.4 职业推荐模块

## 三、非功能需求

### 3.1 性能需求
| 编号 | 需求 | 指标 |
|------|------|------|
| PERF-01 | API响应时间 | AI接口 < 90秒，流式接口即时开始推送，普通接口 < 3秒 |
| PERF-02 | 并发支持 | 支持至少10个并发用户 |
| PERF-03 | 频率限制 | 单用户每分钟最多10次AI调用 |
| PERF-04 | 数据库连接池 | 最大10个连接，最少5个空闲连接 |
| PERF-05 | 流式传输 | AI调用支持SSE流式传输，max_tokens=1200优化响应速度 |

### 3.2 安全需求
| 编号 | 需求 | 指标 |
|------|------|------|
| SEC-01 | 数据传输安全 | API通信使用HTTPS |
| SEC-02 | 跨域控制 | 配置CORS，限制允许的来源 |
| SEC-03 | CSRF防护 | 禁用CSRF（API模式） |
| SEC-04 | 密码安全 | 密码长度不少于6位 |
| SEC-05 | 输入安全 | 所有输入字段禁止非法字符（`<>"'`），长度限制防注入 |

### 3.3 可用性需求
- 小程序界面简洁易用
- 错误提示明确友好
- 加载状态有明确反馈
- 支持微信原生导航体验

### 3.4 兼容性需求
- 微信版本：7.0及以上
- Android 8.0+ / iOS 13.0+
- 使用微信原生WebView渲染，广泛兼容

## 五、接口规范

### 5.1 用户认证接口

**注册**：
```
POST /api/auth/register
Content-Type: application/json

{
  "username": "string",
  "password": "string",
  "email": "string",
  "nickname": "string"
}
```

**登录**：
```
POST /api/auth/login
Content-Type: application/json

{
  "username": "string",
  "password": "string"
}
```

### 5.2 AI服务接口

**AI对话**：
```
POST /api/ai/chat
Content-Type: application/json
Authorization: Bearer {token} (可选)

{
  "prompt": "string"
}

Response:
{
  "code": 200,
  "message": "调用成功",
  "data": "AI回复内容"
}
```

## 六、数据模型

### 6.1 用户表（users）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| username | VARCHAR(50) | 用户名，唯一 |
| password | VARCHAR(255) | 密码 |
| email | VARCHAR(100) | 邮箱 |
| nickname | VARCHAR(50) | 昵称 |
| phone | VARCHAR(20) | 手机号 |
| avatar | VARCHAR(500) | 头像URL |
| created_at | DATETIME | 注册时间 |
| updated_at | DATETIME | 更新时间 |

### 6.2 简历历史表（resume_history）
| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键，自增 |
| user_id | BIGINT | 外键，关联用户 |
| type | VARCHAR(50) | 类型（生成/评估） |
| title | VARCHAR(200) | 标题 |
| content | TEXT | 内容 |
| result | TEXT | 结果 |
| created_at | DATETIME | 创建时间 |
