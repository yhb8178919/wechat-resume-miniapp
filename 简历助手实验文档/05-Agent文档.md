# Agent 文档

## 一、AI Agent 概述

### 1.1 Agent 名称
**简历智能助手 Agent**（Resume Assistant Agent）

### 1.2 Agent 角色定义
本Agent是一个基于DeepSeek大语言模型的智能简历顾问，为求职者提供专业的一站式简历服务，包括简历生成、简历评估、职业推荐和面试模拟。

### 1.3 Agent 能力边界
- ✅ 能够执行：简历生成、简历评估、职业推荐、面试问题生成
- ❌ 不能执行：实际投递简历、联系HR、修改他人系统数据

## 三、Agent 工作流程

### 3.1 简历生成流程

```
用户输入（姓名 + 类型 + 经验 + 技能）
        │
        ▼
构建结构化Prompt
"专业简历制作服务：为{姓名}生成一份{简历类型}。
 工作经验：{年限}年。个人技能：{技能}。
 请按照标准简历格式生成，包括个人信息、
 教育背景、工作经历、专业技能、项目经验等。"
        │
        ▼
调用 DeepSeek API
  - model: deepseek-chat
  - temperature: 0.7（保证一定创造性）
  - max_tokens: 2000（足够生成完整简历）
        │
        ▼
获取AI生成的简历文本
        │
        ▼
保存到历史记录 + 展示给用户
```

### 3.2 简历评估流程

```
用户上传简历 + 选择评估维度
        │
        ▼
构建评估Prompt
"请从以下维度评估简历质量：
 1. 简历结构和格式
 2. 个人信息完整性
 3. 工作经历描述
 4. 专业技能展示
 5. 语言表达和规范性
 6. 整体竞争力
 给出具体评分和改进建议。"
        │
        ▼
调用 DeepSeek API → 获取评估结果
        │
        ▼
解析评估结果 → 展示评分与建议
```

### 3.3 职业推荐流程

```
用户输入（简历主题 + 内容）
        │
        ▼
构建推荐Prompt
"请根据以下简历信息，推荐3-5个最匹配的职业方向。
返回JSON格式：[{"job":"职业","description":"描述","reason":"理由"}]
 简历主题：{topic}
 简历内容：{content}"
        │
        ▼
调用 DeepSeek API → 获取推荐列表
        │
        ▼
JSON解析 → 展示职业推荐卡片
```

## 四、API 接口规范

### 4.1 请求格式

```
POST /api/ai/chat
Content-Type: application/json
Authorization: Bearer {token} (可选)

{
  "prompt": "string - AI提示词"
}
```

### 4.2 响应格式

```json
{
  "code": 200,
  "message": "调用成功",
  "data": "AI生成的文本内容"
}
```

### 4.3 错误码

| 状态码 | code | 说明 |
|--------|------|------|
| 200 | 200 | 调用成功 |
| 400 | 400 | prompt参数为空 |
| 429 | 429 | 调用频率超限 |
| 500 | 500 | AI服务调用失败 |

## 五、频率限制策略

```java
// 单用户每分钟最多 10 次调用
private static final int MAX_REQUESTS_PER_MINUTE = 10;
private static final long RATE_LIMIT_WINDOW_MS = 60_000;
```

- 使用 ConcurrentHashMap 维护每个用户的调用计数
- 使用 synchronized 块保证线程安全
- 超过限制返回 HTTP 429 Too Many Requests

## 六、超时与容错配置

| 配置项 | 值 | 说明 |
|-------|-----|------|
| 连接超时 | 10,000ms | 建立HTTP连接的超时时间 |
| 读取超时 | 60,000ms | 等待API响应的超时时间 |
| 前端请求超时 | 90,000ms | 小程序端请求超时时间 |

## 七、Prompt 工程

### 7.1 Prompt 设计原则
1. **明确角色定位**：告知AI其身份和任务
2. **结构化输入**：将用户信息以结构化方式组织
3. **格式约束**：明确指定输出格式（JSON/文本）
4. **长度控制**：通过max_tokens限制生成长度
5. **温度调节**：temperature=0.7 平衡创造性与稳定性

### 7.2 Prompt 模板
```java
// 简历生成
"专业简历制作服务：为{name}生成一份{type}。"
+ "工作经验：{experience}年。"
+ "个人技能：{skills}。"
+ "请按照标准的简历格式生成，包括个人信息、教育背景、"
+ "工作经历、专业技能、项目经验等部分。"

// 简历评估
"请从以下维度评估简历质量：{dimensions}。"
+ "简历内容：{content}。"
+ "给出具体评分和改进建议。"

// 职业推荐
"请根据以下简历信息，推荐3-5个最匹配的职业方向。"
+ "简历主题：{topic}。简历内容：{content}。"
+ "请严格按JSON格式输出：[{\"job\":\"职业\",\"description\":\"描述\",\"reason\":\"理由\"}]"
```

## 八、安全保障

1. API Key 通过 application.properties 配置管理
2. 日志中不输出完整的API Key
3. 频率限制防止API滥用
4. 用户输入长度控制在合理范围
5. 异常信息统一处理，不暴露内部细节
