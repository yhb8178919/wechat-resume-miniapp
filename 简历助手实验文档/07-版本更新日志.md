# 版本更新日志

## [v1.0.0] - 2026-06-04

### 新增功能
- **用户认证系统**
  - 用户注册（用户名、密码、邮箱、昵称）
  - 用户登录（用户名+密码）
  - 用户名重复检查
  - 个人信息管理（昵称、手机号、头像）
  - 密码长度校验（不少于6位）
  - 邮箱格式校验

- **AI简历生成（page1）**
  - 支持所学专业自由输入，替换简历类型选择
  - 基于DeepSeek AI的智能简历生成
  - 用户输入：姓名、所学专业、工作经验、个人技能
  - 生成结果预览
  - 自动保存生成历史
  - 完整输入校验：姓名2-20字符、专业30字符、工作年限0-60年、技能500字符

- **AI简历评估（page2）**
  - 支持.txt文件上传
  - 6个评估维度可选：
    - 简历结构和格式
    - 个人信息完整性
    - 工作经历描述
    - 专业技能展示
    - 语言表达和规范性
    - 整体竞争力
  - AI自动评分和改进建议

- **职业方向推荐（career）**
  - 基于简历内容智能推荐3-5个职业方向
  - 支持.txt文件导入
  - JSON格式的结构化输出解析
  - 推荐理由展示

- **面试模拟练习（defense）**
  - 10道面试题库随机抽取5题
  - 逐题问答流程
  - 答题进度追踪
  - 通过率统计
  - 历史记录保存

- **简历历史管理（page4）**
  - 简历生成历史查询
  - 简历评估历史查询
  - 历史详情查看
  - 历史记录删除

- **实用工具集成（本地AI页面）**
  - 简历模板（15个行业模板，AI生成简历框架）
  - 面试题库（20道分类面试题，AI生成答题思路+高分示例）
  - 薪资查询（18个热门岗位薪资，AI多维度分析）
  - 技能测评（12个核心技能测试，AI评估标准+提升建议）
  - 求职攻略（15个求职关键环节攻略，AI专业指导）
  - 行业分析（12个热门行业深度分析，AI分析趋势）
  - 职场百科（15个职场知识点，AI解答）
  - 名企直通车（15家热门企业招聘指南，AI介绍）

- **后端服务**
  - Spring Boot 3.2.4 + Java 17
  - RESTful API设计
  - JPA + MySQL数据持久化
  - HikariCP连接池
  - Spring Security安全框架
  - CORS跨域配置
  - DeepSeek API集成与封装
  - 频率限制（每分钟10次/用户）

### 技术架构
- **前端**：微信小程序原生框架
  - WebView渲染引擎（兼容所有微信版本）
  - 自定义导航栏组件
  - cover-view返回按钮（WebView页面）
  - 21个功能页面
- **后端**：Spring Boot 3.2.4
  - Controller层：AuthController、DeepSeekController、HistoryController、ProfileController
  - Service层：UserService、DeepSeekService（流式+非流式双模式）、ResumeHistoryService、StatisticsService
  - Repository层：UserRepository、ResumeHistoryRepository
  - 实体层：User、ResumeHistory
- **数据库**：MySQL 8.0（resume_db）
- **AI服务**：DeepSeek Chat API
