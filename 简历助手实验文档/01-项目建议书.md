# 项目建议书

## 一、项目概述

### 1.1 项目名称
**智能简历助手微信小程序**（Smart Resume Assistant Mini Program）

### 1.2 项目背景
随着就业市场竞争日益激烈，求职者对高质量简历的需求不断增加。传统的简历撰写方式存在以下痛点：
- 撰写简历耗时长、缺乏专业指导
- 简历质量参差不齐，难以突出个人优势
- 面试准备不充分，缺乏模拟练习途径
- 职业方向不明确，缺少个性化职业规划建议

### 1.3 项目目标
开发一款基于AI技术的智能简历助手微信小程序，为求职者提供：
1. **智能简历生成**：根据用户输入的个人信息，利用DeepSeek AI自动生成专业简历
2. **简历智能评估**：上传已有简历，AI多维度评分并提供优化建议
3. **职业方向推荐**：基于用户简历内容，智能推荐匹配的职业方向
4. **面试答辩模拟**：模拟面试答辩场景，提供问答练习与反馈
5. **简历历史管理**：保存生成和评估的简历记录，方便回顾与管理
6. **实用求职工具**：简历模板、面试题库、薪资查询、技能测评，AI实时生成内容
7. **求职资讯服务**：求职攻略、行业分析、职场百科、名企介绍，AI专业解答

### 1.4 项目范围
- **前端**：微信小程序，覆盖简历生成、评估、职业推荐、面试模拟、历史管理、8个实用工具/求职资讯等模块
- **后端**：Spring Boot 3.2 + Java 17，提供用户认证、AI接口代理、数据持久化等服务
- **AI集成**：对接DeepSeek大语言模型API，实现智能内容生成
- **数据库**：MySQL 8.0，存储用户信息、简历历史记录

## 二、项目价值

### 2.1 用户价值
- 降低求职者简历撰写的门槛和时间成本
- 提供专业的简历评估和改进建议
- 帮助求职者明确职业方向和规划
- 通过模拟面试提升面试应对能力

### 2.2 技术价值
- 探索AI大模型在简历领域的应用实践
- 积累微信小程序与Spring Boot后端集成经验
- 验证LLM在职业顾问场景的可行性

### 2.3 商业价值
- 可面向高校就业指导中心、猎头公司等B端客户
- 具备SaaS化运营潜力（会员制、按次收费等模式）

## 三、技术方案

### 3.1 技术架构
| 层级 | 技术选型 |
|------|---------|
| 前端 | 微信小程序原生框架（WebView渲染引擎 + 自定义导航栏组件） |
| 后端 | Spring Boot 3.2.4 + Java 17 |
| 数据库 | MySQL 8.0 + Spring Data JPA + HikariCP连接池 |
| AI服务 | DeepSeek Chat API（deepseek-chat模型） |
| 安全 | Spring Security + CORS跨域配置 |

### 3.2 系统模块
1. **用户认证模块**：注册、登录、个人信息管理
2. **简历生成模块**：AI驱动的简历自动生成（page1）
3. **简历评估模块**：多维度简历质量评估与打分（page2）
4. **职业推荐模块**：基于简历内容的职业方向推荐（career）
5. **面试模拟模块**：答辩问答模拟与反馈（defense）
6. **历史记录模块**：简历生成与评估历史管理（page4）
7. **个人中心模块**：用户信息管理（page3/profile）
8. **实用工具模块**：简历模板/面试题库/薪资查询/技能测评（page5-8，本地AI页面）
9. **求职资讯模块**：求职攻略/行业分析/职场百科/名企直通车（page9-12，本地AI页面）

## 四、项目计划

### 4.1 项目周期
- **阶段一：需求分析与设计**（1周）
- **阶段二：核心功能开发**（3周）
- **阶段三：测试与优化**（1周）
- **阶段四：部署与验收**（1周）
- **总计**：约6周

### 4.2 资源需求
- 开发人员：1-2名（全栈开发）
- 服务器：1台（运行Spring Boot后端 + MySQL）
- API费用：DeepSeek API调用费用
- 微信小程序账号：1个（已注册）

## 五、风险分析

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| AI API不稳定 | 核心功能不可用 | 添加降级方案和缓存机制 |
| API调用费用过高 | 运营成本增加 | 实现频率限制和Token预算控制 |
| 微信审核不通过 | 无法上线 | 严格遵循微信小程序规范 |
| 数据安全问题 | 用户隐私泄露 | 使用Spring Security加密和权限控制 |

## 六、结论与建议

本项目基于市场需求和技术可行性分析，具有明确的用户价值和技术可行性。建议批准立项，按照计划推进开发工作。
